# 2469. Convert the Temperature

🔗 **Problem Link:** https://leetcode.com/problems/convert-the-temperature/

## Problem Summary
Convert a temperature given in Celsius to:
- Kelvin
- Fahrenheit

Return both converted values as a `vector<double>`.

## Approach
- Compute Kelvin using `celsius + 273.15`.
- Compute Fahrenheit using `celsius * 1.8 + 32`.
- Return both values in a vector.

## Time Complexity
- **O(1)**

## Space Complexity
- **O(1)**

## Concepts Used
- Functions
- `vector<double>`
- Floating-point arithmetic
- Mathematical formulas
