# 2235. Add Two Integers

**Problem Link:** https://leetcode.com/problems/add-two-integers/

## Problem Summary
Given two integers `num1` and `num2`, return their sum.

## Approach
- Return the sum of the two integers using the `+` operator.
- No additional data structures or algorithms are required.

## Algorithm
1. Receive `num1` and `num2`.
2. Compute `num1 + num2`.
3. Return the result.

## Time Complexity
- **O(1)**

## Space Complexity
- **O(1)**

## Concepts Used
- Functions
- Return Statement
- Arithmetic Operators
